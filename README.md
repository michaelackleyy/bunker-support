# bunker-support

The support and privacy pages for **Bunker**, an iOS golf shot tracker, served by
GitHub Pages at <https://michaelackleyy.github.io/bunker-support/>.

Two URLs live here, and both are required fields in App Store Connect:

| App Store Connect field | URL |
| --- | --- |
| Support URL | `https://michaelackleyy.github.io/bunker-support/` |
| Privacy Policy URL | `https://michaelackleyy.github.io/bunker-support/privacy` |

Separate from the app's own repository on purpose: this one is public because
Apple requires the pages to be reachable by anybody, and the app repository is a
private backup.

Editing a page here takes effect as soon as Pages rebuilds, with no App Store
review and no new build. That is the main reason to keep the course list and the
answers in here rather than in the app.
